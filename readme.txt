My pages are index, menu, special orders, contact, gallery about us, and my CSS style sheet for the page design. In the home page, the headers and text are separated properly so they give enough space to read without there being an abundance of white space. The Menu page has pictures and names of each dish we provide at the restaurant. The Special Orders page is for specific orders that can be tailored to a customer's needs for the item. On the Contact page, it allows for the user's information to be input so the company can respond within a few days in relation to the query/message from the user. The Gallery page shows off our items visually and allows customers to see the dishes we offer. About Us shows off our staff and writes about the morals and message of the company. The color palette is black text on a white background. Link like the top of each page are shaded blue when hovered or tab keyed onto. The text font is Sans Serif because it is a classic and effective font that is commonly used for accessibility. The breakpoints automatically change depending on the device to accommodate pc access and mobile access. It comfortably fits both screen types and displays the information clearly on any device.
